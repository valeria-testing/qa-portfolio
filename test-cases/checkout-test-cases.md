# Checkout Test Cases

## TC-001 Successful checkout

Steps:

1. Add products to cart
2. Open checkout
3. Enter valid information
4. Finish order

Expected Result:
Order is completed successfully

---

## TC-002 Empty checkout fields

Steps:

1. Open checkout form
2. Leave all fields empty
3. Click Continue

Expected Result:
Validation error appears

---

## TC-003 Whitespace-only input

Steps:

1. Enter only spaces in all fields
2. Continue checkout

Expected Result:
Validation error appears
